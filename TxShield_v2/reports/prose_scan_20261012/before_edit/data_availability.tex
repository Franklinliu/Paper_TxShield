\section{Data Availability}

\Blue{\textbf{Datasets.} \dsystem{} contains 728 transactions, including 364 attacks and 364 benign transactions. The attack cases are drawn from DeFiHackLabs (\url{https://github.com/SunWeb3Sec/DeFiHackLabs}). \done{} contains 95 documented price-manipulation attacks released with DeFiScope~\cite{zhong2025detectingvariousdefiprice}; our evaluation covers 91 cases.}

\Blue{\textbf{Implementation.} The project repository is \url{https://github.com/oumo0/TxShield}. The framework combines historical attack knowledge, two-stage retrieval, adaptive LLM prompting, and XGBoost post-filtering.}
