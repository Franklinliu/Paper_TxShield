# 动机与数据划分补充

本轮按用户确认补充，新增文字标红。

1. 动机：历史攻击检索会向正常但行为相似的交易提供攻击案例；相似性不能等同于恶意性。
2. 设计依据：XGBoost 在攻击与正常交易上学习数值风险；风险同时作用于历史上下文选择及提示词。低风险只取消历史上下文，不终止 LLM 分析，最终仍可以依据交易证据判为攻击。
3. 创新定位：风险引导的上下文选择与提示机制；不宣称 XGBoost 算法本身创新、不宣称首创或已有概率校准证据。
4. 数据划分：根据用户确认，整体交易集合随机打乱后划分；728 条测试交易与 XGBoost 训练交易、实际 RAG 知识库交易均不重叠。未添加按合约、协议或时间隔离的声明；未添加种子、比例或训练与知识库之间是否重叠的结论。

证据状态：实际划分由用户确认，尚未获得对应的训练/知识库 split manifest。此前提供的 history_knowledge.csv 目录与测试集存在 34 个相同 hash 的检查结果仍保留。需要后续提供实际使用的分割清单/索引记录以对齐该目录，不能声称目前已通过文件独立验证无重叠。该待办仅保存在内部核对记录，不加入论文流水账。
